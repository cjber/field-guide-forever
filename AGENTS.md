# Field Guide Forever

A WoW: Forever addon (`Interface 16001`): a cosmetic journal of creatures a character has met, with local progress and
shared catalogue facts. It never grants player power, changes combat or calls protected functions. It requires
ForeverCore (tracker column, report window, error journal, debug log, quest log side tabs, settings chrome, family
page, map canvas); nothing shared is vendored here.

## Gate

```sh
tools/gate.sh            # stylua, luacheck, ruff on tools, every tests/*_spec.lua under LuaJIT, changelog check
tools/gate.sh --changed  # the same, linting only the Lua files changed against origin/main; specs only when a Lua, TOC or XML file changed
bash tools/typecheck.sh  # LuaLS, load graph, shared lints; run after a signature or type change
python3 tools/visual_audit.py && python3 tools/check_screenshots.py   # after a UI or renderer change
```

Set `FOREVER_CORE` to a ForeverCore checkout at `tools/forever-core.txt`'s ref when it is not at `../forever-core`
(always, from a worktree). CI runs the rest (generated data, API docs, repo rules, dead code, package, workflows,
secrets); never run it whole here. `tools/forever_tools/` and `tools/forever_sim/` are copied from forever-core byte for
byte: refresh with their `sync.py update --source <checkout>`, never edit. Release: `.agents/skills/release/SKILL.md`.

## Screenshots

`FOREVER_CORE=<checkout> python3 tools/mockups.py` renders `docs/screenshots/` and `layout.json` from client assets and
a disposable QuestieDB fixture in an ignored cache. A green `check_screenshots.py` and `visual_audit.py` prove
freshness and geometry only: open every README screenshot and the `demo.gif` frames at full size and look for
overlap, clipping, misalignment and truncated labels. Fix the runtime producer and the renderer together, then
re-render; never fix only a PNG. Every user-facing feature has a scene listed in `docs/gallery.md`.

## Invariants

- Lua 5.1; new globals only for SavedVariables, the public API and client-required slash globals. Never add a
  `.luacheckrc` `read_globals` entry except for a real client API.
- Every player-visible phrase lives in `Locales/enUS.lua`; UI code uses `L["whole sentence"]`.
- Creature names, levels, ranks and spawn placement are never hand-written or vendored: `Integrations/QuestieDB.lua` is
  the only runtime reader of QuestieDB. The old hand-maintained catalogue must not return.
- `Data/Client.lua` is generated by `tools/gen_zones.py` from pinned wago.tools exports (`BUILD` pins it; the daily
  `refresh-data.yml` moves it): never hand-edit. The screenshot art pin is separate, in `tools/ui_art.py`.
- Saved progress is character-local. Rarity classification depends only on stable QuestieDB NPC ids and rank fields,
  never on personal progress. Match names case-insensitively only to resolve a localized name from a kill or sighting,
  or to migrate old records.
- SavedVariables stay flat and serialisable: no frames, functions, userdata or the session sighting log.
- `Core/Model.lua` is pure (no WoW API, I/O or globals beyond `ns.Model`); inject random sources in tests.
- Kill detection writes SavedVariables and schedules refresh work; it never touches UI frames. Every possibly secret
  value (GUIDs, unit names) is read through `ns.Readable`; handlers use `ns.core.SafeCall`.
- `Core/Require.lua` is the API floor; `Core/API.lua` is the versioned addon-to-addon contract and returns nil until
  state and catalogue are ready. `Core/LegacyIds.lua` is a migration map: remove it in the release after schema 2.
- Player-facing notes go in `changes/<issue>.md`; only the release commit edits `CHANGELOG.md`. Credit players, never
  cjber, per WFA-33. `.pkgmeta` never includes tools, tests or screenshots. Read the live roots in
  `.sloppatrol/instructions.md` before deleting code as unused.

## Standards

- `repo-standards`: the RS-* requirements every cjber and agent-labs-dev repo meets; its `audit.py` checks this repo.
- `wow-forever-addon`: the WFA-* addon requirements (UI, assets, README and store page, CI and release); wins where
  stricter. UI and screenshot work also reads `wow-retail-ui-style` and its asset registry in forever-core.
